Bench sheet · Reed–Solomon RS(8,4) on Cmod S7

Seven-Segment Display Wiring

Displays: 8 × TD-7SGCC (1 digit, common cathode) Drivers: 8 × BC547B Top: rs_top (segments on DIP 41–48)

Before you start

  • Unplug the USB cable whenever you move a wire.
  • Pull the Hamming-project LEDs out of DIP pins 1–8 and 41–48. Pins 1–8 drive the transistors and 41–48 the segments.
  • Never connect anything to DIP pin 24. It is 5 V. Leave the Pmod connector empty.
  • Program the bitstream built after the segments moved to pins 41–48.

Segment wiring

Each segment goes from its FPGA pin to display 1, then hops display 1 → 2 → 3 … → 8 on the same pin number. That makes 8 wires from the FPGA plus 56 hops between displays. Tick one box per wire.

Build order

Place the parts

USB unplugged

Put displays 1–8 left to right across the center gap, decimal points toward you, with one empty column between neighbours. Eight displays fill most of a full-size breadboard, so put the transistors on a second breadboard if needed, with legs in separate columns. Run DIP pin 25 to the GND rail, and link the GND rails of both boards.

Wire display 1 and Q0

USB unplugged

Run the 8 “FPGA→1” wires: DIP pins 41–48 to display 1. Wire Q0: E → GND, B ← DIP pin 1, C → display 1 COM.

Test one digit

USB plugged in

Program rs_top.bit and press BTN1. The display must stay dark and LED3 must blink. If a segment lights before any message, a wire is on a power pin. Then send:

cd C:\users\johna\ReedSolomon
python tools\rs_host.py COM6 --hex 1234 --delay 4

Display 1 should show 1. Replace COM6 with your port.

Add displays 2–4 and Q1–Q3

USB unplugged

Hop each segment 1→2, 2→3, 3→4 and wire Q1–Q3. Test again: displays 1–4 should show 1 2 3 4.

Add displays 5–8 and Q4–Q7

USB unplugged

Finish the hops to display 8 and wire Q4–Q7. Before powering, count 8 wires on DIP 1–8, 8 on DIP 41–48 and 1 on pin 25, and nothing on pin 24.

Full test

USB plugged in

Run the mode tests below. Press BTN0 to change mode; LED1–LED0 show the mode in binary.

Troubleshooting

SymptomLikely cause
Everything blankNo message sent yet, GND not linked to the FPGA, or a transistor turned around
Segment lights before any messageA wire on a power pin. Unplug now.
One display deadIts transistor, its COM wire, or a broken hop on every segment
One segment missing from display N onwardThe hop into display N for that segment
Garbled charactersTwo segment wires swapped
Digits in the wrong orderBase or collector wires swapped
Dim displayExpected: each digit is lit 1/8 of the time. Dim the room for video.
“got 0 of 10 reply bytes”Wrong COM port, board not programmed, or press BTN1
